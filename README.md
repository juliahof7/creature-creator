# creature-creator 

The **Creature Creator** is a Python-based application that allows users to generate a brand-new hybrid creature by combining any two creatures of their choice. The result is a fun, randomly named creature complete with stats and a graphical confirmation!

---

#  How It Works

1. The user is prompted to enter two creature names.
2. A new hybrid name is generated by combining parts of each.
3. Random creature statistics are assigned (weight and diet).
4. A confirmation window displays the creature's name and some fun graphics.

---

#  File Structure

- main.py – main driver file (the app starts here).
- creature.py – creature class logic (hybrid name, stats, etc.)
- graphics.py – this is for showing the creature confirmation graphic using tkinter.
- requirements.txt – if you use external libraries like Pillow, add them here for easy setup.
- README.md –  explains the project.
- assets/ – (folder) for any images or graphics.

---

##  Technology Used

- **Python 3**
- `tkinter` for GUI
- `random` module for stat generation
