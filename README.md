# creature-creator 

This **Creature Creator** project was created for my SWDV 220 Course. It consists of a Python-based application that allows users to generate a new hybrid creature by combining any two creatures of their choice. The result is a randomly named creature with stats and a graphical confirmation.

---

#  How It Works

1. The user is prompted to enter their two creature names.
2. A new hybrid name is generated by combining parts of each.
3. Random creature statistics are assigned (for example: weight and diet).
4. A confirmation window displays the creature's name and some graphics.

---

#  File Structure

- main.py – main driver file (the app starts here).
- creature.py – creature class logic (hybrid name, stats, etc.)
- graphics.py – this is for showing the creature confirmation graphic using tkinter.
- requirements.txt – if the user uses external libraries like Pillow, they can add them here for easy setup.
- README.md –  this file explains the project.
- assets/ – (folder) for any images or graphics.

---

##  Technology Used

- **Python 3**
- `tkinter` for GUI
- `random` module for stat generation
